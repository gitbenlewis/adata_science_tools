Understand your AnnData.

A matrix of measurements, with the information that gives each row and column meaning.

What is AnnData?

AnnData means annotated data. It keeps measurements and their metadata together. Observations might be cells or samples; variables (called features in this app) might be genes, proteins, or metabolites.

adata.X · Measurements
A numeric matrix: rows are observations, columns are features.
adata.obs · Observation metadata
One row per observation, aligned with X rows. Columns can describe treatment, subject, or batch.
adata.var · Feature metadata
One row per feature, aligned with X columns. Columns can hold gene symbols or feature annotations.

In the demo, X has 32 rows × 8 columns, obs has 32 rows, and var has 8 rows. Observation and feature identifiers keep these pieces aligned.

Other parts of the structure

layers
Additional matrices with the same shape as X, such as counts or transformed measurements.
obsm and varm
Arrays aligned to observations or features, such as cell coordinates or gene loadings.
obsp and varp
Pairwise matrices between observations or between features, such as a neighbor graph.
uns
Unstructured metadata, such as analysis settings and color palettes.
raw
An optional saved X and its feature annotations. Its name does not guarantee unprocessed counts.

The studio uses X, a layer, or raw as its matrix source. Storing an embedding or graph does not mean every AnnData field has a dedicated GUI analysis.

From a dataset to your first result

  1. Load or try a dataset

    Open Datasets and choose Open demo dataset, or upload your own data. An .h5ad file preserves additional AnnData fields. A CSV bundle creates X, obs, and var from adata.X.csv, adata.obs.csv, and adata.var.csv.

    For CSVs, put row identifiers in the first column of each file. X row IDs must match obs row IDs, and X feature headers must match var row IDs. The app aligns metadata by these identifiers.

  2. Inspect the structure

    Use the Observations, Features, and Matrix previews. Check dimensions, identifiers, and group labels before analyzing. CSV metadata starts as text; use Metadata types in the studio when a column should be numeric.

  3. Choose your measurements

    In Analysis studio, select a Matrix source and features. The first three features are selected initially. Filters keep only the chosen observations. Check whether your selected matrix contains counts, normalized values, or transformed values before choosing a method.

  4. Run a plot or statistical method

    Start with Histogram and select Run analysis. To compare groups in the paired demo, choose a paired test with condition as the group column, Reference and Treatment as the groups, and subject as the pairing column. Match the method to your study design.

    Statistical tests use your selected feature set for false discovery rate (FDR) correction. Changing that set can change adjusted p-values. Plots that require feature-level statistics use supplied or previously computed results.

  5. Review and download

    Open Results & downloads to inspect each run, check warnings, and download available figures, tables, settings, and reproduction scripts. Your source dataset stays unchanged. Download anything you want to keep before the workspace retention period ends.

ANALYSIS PIPELINES

A workflow for your question.

Run a set of related analyses with one shared data selection.

Configure your workflow

    Distribution plots use the first 24 selected features at most. Means and tests use every selected feature. Descriptive plots and means show all groups retained by your filter; tests compare only your reference and target groups. FDR correction uses the tested feature set.

    Use independent tests for independent experimental units and paired tests for matched subjects. These workflows use your chosen matrix as supplied; they do not normalize data. Each step runs separately, so a failed step does not prevent the others from completing.
